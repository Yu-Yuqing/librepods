# LibrePods 1.0.10-RC3

底部导航增加「设备」「设置」「统计」，可查看累计佩戴时长、次数、平均时长及分布图。

统计页向左滑动可从日切到周、从周切到月。滑动过程中，页面和标签选中框同步跟随手指，松手后吸附到目标页。向右滑动可返回，也可以点顶部标签直接选择时段。点选柱子仍在图中查看对应时长。

连续佩戴超过 30 秒才计为一次。较短记录仍贡献累计时长，但不列入佩戴明细，也不参与平均每次时长。跨午夜按整次佩戴判定，既有记录与导入记录使用相同规则。

在「统计」右上角点「⋮」，可导出全部佩戴记录到一个 JSON 文件。请将文件保存到下载目录或自己的云盘，重装后在同一菜单选择「导入佩戴记录」。备份包括各次佩戴的开始与结束时间。进行中的记录导出到当时为止。导入时保留本机记录，同一起点的较长备份可补全历史记录，其他重叠区间会跳过。文件无效时不修改数据库。
