# LibrePods 1.0.10-RC4

- 底部导航的标准内容高度从 80 dp 调整为 52 dp。页面底沿与导航栏平直接合。
- 设备、设置和统计直接切换，设置列表按需加载。统计切换日、周、月时会保留已显示的内容，直到新数据就绪。
- 佩戴时长分布增加纵轴刻度和网格线。点击柱子会在图内显示对应时段的佩戴时长。从「每日明细」可打开某天的记录。
- 统计保留累计时长、次数和平均每次时间，移除了「最长一次时间」和页尾说明。

## 安装包

- 已安装上一版 RC3 的手机可以用 LibrePods-RC4-Upgrade.apk 覆盖更新，保留设置和佩戴记录。这是本次较早的同签名构建，已经包括去圆角、简化导航与图表交互。其底栏在部分布局下仍会偏高，密集月图也可能选中相邻日期。
- LibrePods-RC4.apk 是与此源码对应的完整优化版，包含标准字号下的 52 dp 底栏和最终点按校正。它使用新的签名，可用于全新安装。Android 无法用它直接覆盖上述两个旧签名安装包。
