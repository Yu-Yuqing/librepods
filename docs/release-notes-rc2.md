# LibrePods 1.0.10-RC2

**下载安装：[LibrePods-FOSS-v1.0.10-RC2-release.apk](https://github.com/Yu-Yuqing/librepods/releases/download/v1.0.10-RC2/LibrePods-FOSS-v1.0.10-RC2-release.apk)**

本页只提供一个安装 APK。GitHub 自动生成的 Source code 是源码，不用安装。

## 本次修复

- 修复双设备连接时，耳机回盒合盖后重新打开，Mac 先连接导致手机未自动回连、需要在 App 内手动重新连接的问题。
- 新增默认开启的“开盖后优先连接手机”设置。检测到开盖后主动连接已配对的手机，即使另一台设备已先连接；自动重试限于 5 秒内，最多两次，音乐和控制连接并行发起。
- 单次未建立的控制连接约 1.8 秒后关闭，避免阻塞后续尝试；成功连接后停止重试，不主动请求其他设备交出音频。
- 修复耳机广播地址变化时，同一毫秒收到多条状态可能读到旧合盖状态、提前取消回连的问题。

保留 RC1 的系统蓝牙电量同步、语音助手后台/锁屏权限引导及 Material 列表布局调整。

## 验证与限制

- 回连修复测试版已通过 USB 安装实测，用户确认使用正常。
- 一轮实测中，从手机收到开盖广播开始，控制连接约 1.9 秒、音乐连接约 2.3 秒；耳机报告两台设备同时在线。该结果不代表所有设备及场景都能保证 5 秒内连接。
- 通话连接在同轮测试中约 9 秒就绪；5 秒是自动重试窗口，不是所有蓝牙通道的完成保证。
- 发布包使用 Release 构建，版本代码 85，与 RC1 和本次测试版签名一致。

## 安装说明

- 本社区 RC1 及本次回连测试版可直接覆盖更新，保留现有配置。
- 在 App 设置中可关闭“开盖后优先连接手机”。双设备功能仍需原有的 Apple 设备模拟配置与相应框架支持。
- 系统电量同步需要 Android 14+ 和 LSPosed/Vector，在框架中启用 LibrePods 并勾选“蓝牙（com.android.bluetooth）”。
- 上游原版使用不同签名，切换时需先备份设置并卸载旧版；使用旧 Root 模块的用户需先停用旧模块，避免签名冲突。
